# GalaxyBrain — Claude Code Guide

GalaxyBrain is a static Astro 5 site that publishes an Obsidian vault as an interactive 3D knowledge graph. The full design history and architecture rationale live in [`Context.md`](Context.md). This file covers what you need to work in the codebase day-to-day.

## Commands

```bash
pnpm dev          # dev server at localhost:4321 (hot-reload)
pnpm build        # runs sync-titles.mjs then astro build → dist/
pnpm preview      # serve dist/ locally
```

## Project layout

```
vault/            ← Obsidian markdown files (source of truth — edit here, not src/)
src/
  components/     ← React islands: FullGraph.tsx, LocalGraph.tsx, GraphNodeFactory.ts
  integrations/   ← Astro build integrations (graph-builder, asset-collector, block-indexer)
  plugins/        ← Remark plugins (remark-vault-images, remark-transclusion)
  lib/            ← Shared TS: types.ts, vault-parser.ts, link-resolver.ts, remark-wikilinks.ts
  layouts/        ← BaseLayout.astro (theme, anti-FOUC), NoteLayout.astro (two-column + sidebar)
  pages/          ← index.astro (full graph), notes/[...slug].astro (note pages)
  styles/         ← global.css, note.css, graph.css, callouts.css
scripts/
  sync-titles.mjs ← syncs note filenames → frontmatter titles; runs automatically before build
public/
  graph.json            ← full graph data (52 nodes, gitignored, regenerated at build)
  graph/[noteId].json   ← per-note 1-hop neighbourhood JSONs (gitignored)
  vault-assets/         ← copied vault images (gitignored, built by asset-collector)
.astro/
  vault-images.json     ← image path map (gitignored, built at build time)
  block-index.json      ← block ID index for transclusion (gitignored, built at build time)
```

## Architecture notes

**Graph components use `client:only="react"`** — `react-force-graph-3d` needs browser globals (WebGL, `window`). Never remove this directive.

**Remark plugin order is fixed** — changing the order in `astro.config.mjs` breaks the build:
1. `remark-vault-images` — must consume `![[img]]` before other plugins see it
2. `remark-transclusion` — must run before `remark-wikilinks` consumes `[[...]]`
3. `remark-wikilinks`
4. `remark-obsidian`
5. `rehype-raw` — must be last (processes raw HTML all plugins emit)

**Build-time JSON files** (`.astro/*.json`) are generated by integrations and read by remark plugins via `readFileSync`. They are not shipped to the browser. Delete them only to force a clean rebuild.

**All colours come from CSS variables** — `html.dark { … }` / `html.light { … }` in `global.css`. Never hardcode hex values in CSS or JS; use the variable tokens.

**Theme is propagated to React via `CustomEvent`** — the toggle in `BaseLayout.astro` dispatches `'theme-change'`; `FullGraph.tsx` and `LocalGraph.tsx` listen for it. Cross-tab sync uses the `'storage'` event.

**`nodeThreeObject` must stay referentially stable** — both graph components use `useRef(isDark)` + `fgRef.current?.refresh?.()` to update colours on theme change without restarting the force simulation. Do not replace this with direct `isDark` state reads inside the callback.

**Note publishing gate** — only notes with `publish: true` in frontmatter generate routes, graph nodes, or backlinks. Notes without it are completely invisible at build time.

## Adding things

| Task | Files to touch |
|---|---|
| New node shape | `src/lib/types.ts` (union), `src/components/GraphNodeFactory.ts` (geometry case) |
| New frontmatter field | `src/lib/types.ts` (interface), `src/integrations/graph-builder.ts` (mapping + defaults on tag/ghost nodes) |
| New CSS token | `src/styles/global.css` (`html.dark` and `html.light` blocks) |
| New remark plugin | `astro.config.mjs` (add to array, mind the order) |

## Conventions

- TypeScript strict mode — no `any` without a comment explaining why
- Remark plugins must never throw — wrap risky work in try/catch and log a warning
- Graph builder must produce valid JSON even when individual notes are malformed
- No external CSS frameworks — plain CSS custom properties only
- React components are self-contained islands; don't share state across islands via module scope
